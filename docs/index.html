Getting started

How it works

Run beside Warframe in Borderless Windowed. Panels stay click-through until you unlock them.

  1. 01

    Install & launch

    Windows: Setup or portable. Linux: AppImage or .deb. The companion opens from the tray / app menu.

  2. 02

    Enable what you need

    Toggle modules and place panels on the Layout tab — including relic and riven popups.

  3. 03

    Play with intel on-screen

    Hotkeys toggle the overlay, unlock drag, scan relic rewards, and grade riven rerolls.

Modules

Built for the session

One job per panel — live worldstate, reward picks, riven compares, and local inventory.

01

Live worldstate

Cetus, Vallis, Cambion, fissures, Baro Ki’Teer, Nightwave, Archon Hunt, Invasions, and arbitration timers with real countdowns.

02

Relic reward overlay

Scan the fissure pick screen (hotkey or EE.log). See set names, owned counts, market platinum, and parts you still need.

03

Riven grader

On the Kuva Cycle compare screen, grade current vs new roll and get a keep / take recommendation.

04

Layout your way

Drag every panel on a mock monitor in the app — or unlock in-game with Ctrl+Tab and reposition on the fly.

05

Inventory stays local

Optional sync via warframe-api-helper or AlecaFrame exports. Data never leaves your PC for “needed for set” tags.

Safety

Why this is safe to run

You’re downloading an Electron app (Windows installer/portable or Linux AppImage/deb) — here’s exactly what it does and doesn’t do.

  • Open source Full code on GitHub. Review it, fork it, or build from source.
  • Local-first Inventory files and OCR stay on your machine. No cloud account for core features.
  • No telemetry The app doesn’t phone home for analytics. Updates come from GitHub Releases via electron-updater.
  • SmartScreen / unsigned Windows builds aren’t code-signed yet, so SmartScreen may warn on first launch. Linux AppImages are unmarked binaries — verify the download from this site or the official GitHub release.

Support

FAQ

Quick answers before you install.

Does this work on Linux?

Yes — with Warframe via Steam + Proton. Use the AppImage or .deb. EE.log is auto-detected from your Proton compatdata/230410 prefix. Overlay and OCR work best on X11 / XWayland with Borderless Windowed. Inventory sync runs the Windows helper through Proton’s wine, or import inventory.json manually.

Windows says the app is unrecognized / SmartScreen

The release isn’t code-signed yet. Choose “More info” → “Run anyway” if you downloaded from this site or the official GitHub Releases page. Source is public if you want to verify or build yourself.

I can’t see the overlay in-game

Set Warframe to Borderless Windowed. Exclusive fullscreen draws above the overlay. Then press Alt+Shift+V to toggle the overlay on. On Linux, prefer an X11 session (or XWayland) if the overlay doesn’t appear under pure Wayland.

Where did the companion window go?

Closing it leaves the app in the system tray. Click the tray icon or press Alt+Shift+C to reopen.

Does this read my account or steal data?

No. Optional inventory sync uses a local helper or export file on your PC. Relic and riven scans use on-device OCR of what’s already on screen. Nothing is uploaded for those features.

How do relic and riven scans work?

On the fissure reward screen press Alt+Shift+F (or wait for EE.log detection). On the Kuva Cycle compare screen press Alt+Shift+G. Place those popups under Layout in the companion.

How do I add the LFG Discord bot?

Use Add to Discord (needs Manage Server), then follow the LFG Discord setup guide (/lfg setup, /lfg link). Legal: Terms · Privacy.

How do I report a bug?

Use the website Report a bug form (opens a prefilled GitHub Issue), or in the app go to Help → Report a bug for diagnostics. Browse existing issues first if you can.
