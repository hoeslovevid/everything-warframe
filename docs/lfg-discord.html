LFG Discord setup

Hub bot · Join / Leave / Whisper · companion board sync

Three steps: add the bot to a server you manage, point it at an LFG channel, then link your Warframe IGN so Join and members-only announce work.

Add to Discord Get the companion

Invite link copied.

  1. 01

    Invite the bot

    Needs Manage Server. Scopes: bot + applications.commands. Permissions include Send Messages, Embed Links, Read Message History, and Manage Webhooks.

  2. 02

    Run /lfg setup

    Pick the channel that should receive hub squads: /lfg setup channel:#your-lfg. Optional: members_only:True (only hosts in this server) and activities:relic,fissure (comma-separated allowlist). Check with /lfg status or /lfg help.

  3. 03

    Link IGN & post

    Hosts: /lfg link ign:YourIgn (same name as in the companion). Post a squad from the LFG tab — Discord gets a live embed with Join / Leave / Whisper. Joins update the hub roster; hosts can get a DM when someone Joins.

Useful commands

  • /lfg help — short checklist and command list
  • /lfg status — current channel, members-only, activity filter
  • /lfg clear — stop announcing in this server
  • /lfg unlink — remove your saved IGN

Companion tips

  • After you post, the app shows whether Discord announced (or skipped members-only / activity filters).
  • Advanced hub settings → Discord checklist has the invite and this guide. Personal webhooks are optional and stay on your machine.
