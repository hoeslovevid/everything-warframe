Privacy Policy

Effective date: 29 August 2026 · Last updated: 29 August 2026

This Policy explains what information Everything Warframe processes when you use the desktop companion, this website, the LFG hub API, and the Discord LFG bot — and what we do not collect. It is written to be suitable for Discord’s application linking / verification privacy URL requirements.

Summary Controller Desktop app Website LFG hub Discord bot Purposes Sharing Retention Security Children Your rights International Changes Contact
Short version: The companion keeps OCR, inventory, and settings on your PC by default. The Discord bot and public LFG hub only store what is needed for squad listings and server setup (Discord IDs, optional linked IGN, guild channel config). We do not sell personal data. Bug reports are sent only when you open GitHub.

1. Privacy summary

  • No Everything Warframe account and no advertising trackers on this static GitHub Pages site.
  • Desktop: screen capture and OCR run locally; inventory stays local unless you export it yourself.
  • Discord bot: processes Discord user/guild/channel/message IDs, interaction payloads, and optional Warframe IGN you link with /lfg link.
  • LFG hub: stores open squad listings (host IGN, platform, mission text, roster client IDs, expiry) until they expire or are closed.
  • Updates: the app may check GitHub Releases for new versions (standard HTTP request to GitHub).

2. Who is responsible

For hosted components operated by the project (public LFG hub, Discord bot application, this website), the project maintainer of hoeslovevid/everything-warframe is the data controller for the limited server-side data described below. If you self-host the LFG API or run your own Discord webhook, you are the controller for that deployment.

Discord Inc. is an independent controller for data processed on Discord’s platform under Discord’s own Privacy Policy. Digital Extremes is independent for Warframe account data — we do not receive your Warframe password or official account credentials.

3. Desktop companion (local-first)

3.1 Data that typically stays on your device

  • App settings, layout anchors, hotkeys, theme, module toggles;
  • Cached worldstate / catalog data used for offline-friendly UI;
  • Optional inventory index derived from local helper output or import files;
  • OCR crops / debug folders if you enable debugging;
  • Optional crash log file if you opt in to local crash reporting;
  • Optional personal Discord webhook URL (stored locally; not sent to the LFG hub).

3.2 Screen capture & OCR

Relic and riven features capture regions of your screen (or a persistent capture stream) and run OCR on your device to read reward or riven text. Captures are not uploaded to Everything Warframe servers for those features. You control OS screen-share permissions (especially on Linux/Wayland).

3.3 Network calls the app may make

  • Public Warframe worldstate / item catalog providers;
  • Optional warframe.market or price helpers you use;
  • GitHub Releases for auto-update checks;
  • Your configured LFG hub URL (default community hub or local / custom);
  • Optional personal Discord webhook you paste in settings;
  • GitHub Issues when you choose Report a bug / crash prompt (browser opens; you submit).

We do not operate a telemetry backend that silently phones home with gameplay or OCR images.

4. This website (GitHub Pages)

The site is static HTML/CSS/JS. We do not run our own analytics cookies. GitHub Pages / GitHub may process standard server logs (IP address, user agent, timestamps) under GitHub’s privacy terms when you load pages or assets. The download buttons fetch the latest release metadata from GitHub’s public API in your browser.

The Report a bug page builds a GitHub Issue URL in your browser and opens it — the description you type is only sent when you submit on GitHub while signed in.

5. LFG hub API (community or self-hosted)

When you use a networked hub (not pure local mode), listings may include:

  • Host Warframe IGN and optional title / mission / relic / notes text you enter;
  • Platform, region, language, slot counts;
  • Member roster entries (IGN + opaque clientId; Discord joins use discord:<userId>);
  • Created / expiry timestamps; host token for edit/delete (secret to the host client);
  • Discord message references (discordMessageId / per-guild posts) so embeds can be updated or closed.

Expired listings are purged on a schedule. Closed squads are removed and related Discord messages may be edited/deleted by the bot.

6. Discord LFG bot — detailed processing

Discord application client ID: 1543118817654476840. Bot invite (user-chosen server): Add to Discord.

6.1 Permissions requested

Typical permissions: Send Messages, Embed Links, Read Message History, Manage Webhooks (for optional channel webhook fallback). Scopes: bot and applications.commands. No privileged Gateway intents (e.g. Server Members Intent) are required for individual guild.members.fetch(userId) checks used by members-only announce.

6.2 Categories of Discord-related data

  • Guild settings: guild ID, announce channel ID, optional webhook URL, configuring Discord user ID, configured-at time, members_only flag.
  • User profiles (optional): Discord user ID ↔ Warframe IGN from /lfg link (and clearable via /lfg unlink).
  • Interactions: slash commands and button clicks (Join, Leave, Whisper) including Discord user ID, username display as provided by Discord, and modal IGN input if not linked.
  • Messages: message IDs of bot-posted LFG embeds for live roster edits and cleanup.
  • Membership check: for members-only guilds, whether a Discord user ID linked to the host IGN is currently a member of that guild (boolean outcome; used to decide whether to announce).

6.3 What the bot does not do

  • Does not read general channel history beyond what Discord provides for its own messages / interactions;
  • Does not scrape DMs;
  • Does not sell Discord data;
  • Does not require email or phone beyond what Discord already has;
  • Does not store payment information.

7. Purposes & legal bases

We process information to:

  • Provide LFG listing, Discord announce, Join/Leave/Whisper, and setup commands;
  • Enforce members-only announce and prevent posting to unconfigured guilds;
  • Operate and secure the public hub (abuse mitigation, expiry cleanup);
  • Distribute software updates and documentation;
  • Respond to issues you file on GitHub.

Depending on your region, bases may include performance of a contract (providing the Service you request), legitimate interests (security, abuse prevention, open-source project operations), and consent (optional crash opt-in, optional IGN link, optional personal webhook).

8. Sharing & processors

  • Discord — interactions and messages are processed on Discord’s infrastructure.
  • GitHub — hosting source, Releases, Pages, and Issues you create.
  • Hosting providers for the public LFG API (e.g. Railway or similar) act as processors/infrastructure for listing storage.
  • Other users see LFG content you publish (IGN, mission text, roster) in the companion and in Discord channels where the bot posts.

We do not sell personal information.

9. Retention

  • LFG listings: until expiry, host delete, or purge job; Discord embeds updated/removed accordingly.
  • Guild settings & IGN links: until cleared via bot commands or database reset by the hub operator.
  • Desktop local data: until you clear app data / uninstall; optional cloud settings folder only if you configure it.
  • GitHub Issues: retained under GitHub’s policies for the repository.
  • Server logs: subject to host / GitHub retention defaults (typically short operational windows).

10. Security

We use industry-reasonable measures for hosted components (HTTPS, restricted bot token storage in host env vars, least-privilege Discord permissions). No method is 100% secure. Protect your Discord server permissions, webhook URLs, and host tokens. Never share DISCORD_BOT_TOKEN publicly.

11. Children

The Service is not directed to children under 13 (or the minimum age required by Discord / your country). Do not use the bot or hub if you are under the applicable age. We do not knowingly collect children’s data; contact us to delete if you believe we have.

12. Your rights & choices

Depending on your location, you may have rights to access, correct, delete, or restrict processing of personal data, and to object or lodge a complaint with a supervisory authority. Practical controls:

  • /lfg unlink — remove linked IGN;
  • /lfg clear (admin) — remove guild announce config;
  • Leave / kick the bot from your Discord server;
  • Close or let expire your LFG listings; uninstall the app and delete userData;
  • Open a privacy request Issue for hub/bot deletion help (include Discord user ID / guild ID as needed).

13. International transfers

Hosting and Discord/GitHub infrastructure may process data in the United States or other countries. If you access the Service from the EEA/UK/elsewhere, you understand these transfers are inherent to using those platforms. Self-hosting keeps hub data in your chosen region.

14. Changes to this Policy

We may update this Policy by posting a new version here with an updated date. Material Discord-related changes may also be called out in project docs or Releases. Continued use after the effective date means you acknowledge the update.
